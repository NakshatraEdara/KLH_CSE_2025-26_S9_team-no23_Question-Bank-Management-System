Question:
What is the load factor alpha of a hash table with n stored entries and m total slots?

Options:
A. alpha = n / m
B. alpha = m / n
C. alpha = n * m
D. alpha = log(n / m)

Correct Answer: A

Explanation:
The load factor alpha is defined as n / m. When alpha exceeds a designated threshold (such as 0.75 in Java's HashMap), the table is dynamically resized and rehashed.
