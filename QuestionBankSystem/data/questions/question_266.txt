Question:
What is the time complexity and standard space complexity of the Wagner-Fischer algorithm for Edit Distance between strings of length m and n?

Options:
A. Time: O(m * n), Space: O(m * n)
B. Time: O(m + n), Space: O(1)
C. Time: O(2^(m+n)), Space: O(m)
D. Time: O(m^2 * n^2), Space: O(n)

Correct Answer: A

Explanation:
Wagner-Fischer computes an (m+1) x (n+1) table where each cell takes O(1) time, yielding O(m * n) time and O(m * n) full table space.
