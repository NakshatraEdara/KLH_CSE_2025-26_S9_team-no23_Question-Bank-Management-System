Question:
Which tree traversal of a Binary Search Tree visits all keys in strictly ascending sorted order?

Options:
A. In-order traversal
B. Pre-order traversal
C. Post-order traversal
D. Level-order traversal

Correct Answer: A

Explanation:
In-order traversal recursively visits (Left Subtree, Current Node, Right Subtree), which directly outputs BST keys in monotonically non-decreasing order.
