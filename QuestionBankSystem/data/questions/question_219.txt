Question:
In solving the Word Search puzzle on a 2D character grid, why is it critical to mark the current cell as visited before recursing and unmark it when returning?

Options:
A. To prevent reusing the same letter cell multiple times within a single word path while allowing other paths to reuse it later
B. To delete invalid characters from memory
C. To avoid stack overflow in Java
D. To sort the grid characters

Correct Answer: A

Explanation:
Setting grid[r][c] = '#' prevents self-intersection during the current path exploration. Restoring the character on backtrack leaves the board pristine for exploring alternative candidate words.
