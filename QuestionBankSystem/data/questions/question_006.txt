Question:
In an XOR Linked List (memory-efficient doubly linked list), how is each node's single pointer field calculated?

Options:
A. bitwise AND of predecessor and successor memory addresses
B. bitwise OR of predecessor and successor memory addresses
C. bitwise XOR of predecessor and successor memory addresses
D. difference of predecessor and successor memory addresses

Correct Answer: C

Explanation:
An XOR linked list stores address(prev) ^ address(next) in each node, allowing bidirectional traversal using previous address knowledge while using only one pointer field per node.
