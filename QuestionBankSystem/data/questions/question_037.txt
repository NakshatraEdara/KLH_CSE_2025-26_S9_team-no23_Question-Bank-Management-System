Question:
What is the average number of comparisons made by Linear Search on an array of size n when the target element is equally likely to be anywhere in the array?

Options:
A. (n + 1) / 2
B. n / 4
C. log2 n
D. n^2

Correct Answer: A

Explanation:
The average number of comparisons is the sum from i=1 to n of i / n, which equals (n(n+1)/2)/n = (n + 1) / 2.
