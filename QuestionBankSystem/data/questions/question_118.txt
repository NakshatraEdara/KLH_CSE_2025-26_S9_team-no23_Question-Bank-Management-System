Question:
Which data structure is fundamentally used to implement Breadth-First Search (BFS)?

Options:
A. Queue
B. Stack
C. Max-Heap
D. Disjoint Set

Correct Answer: A

Explanation:
BFS explores vertices in order of increasing distance from the source using a FIFO Queue to buffer discovered vertices level by level.
