Question:
How can BFS find the shortest path from a start vertex S to all other vertices?

Options:
A. BFS guarantees finding the shortest path in terms of edge count in unweighted graphs
B. BFS finds shortest paths only if all edges have negative weights
C. BFS requires running Floyd-Warshall first
D. BFS works only on directed acyclic graphs

Correct Answer: A

Explanation:
Because BFS explores frontier vertices level by level (edge by edge), the first time an unvisited vertex is reached, the path length (edge count) is guaranteed to be minimal.
