Question:
What is the suffix array for the string 'banana' (1-indexed or 0-indexed)?

Options:
A. 0-indexed: [5, 3, 1, 0, 4, 2] corresponding to 'a', 'ana', 'anana', 'banana', 'na', 'nana'
B. [0, 1, 2, 3, 4, 5]
C. [5, 4, 3, 2, 1, 0]
D. [1, 3, 5, 0, 2, 4]

Correct Answer: A

Explanation:
Suffixes sorted alphabetically: 5 ('a'), 3 ('ana'), 1 ('anana'), 0 ('banana'), 4 ('na'), 2 ('nana'). Hence, SA = [5, 3, 1, 0, 4, 2].
