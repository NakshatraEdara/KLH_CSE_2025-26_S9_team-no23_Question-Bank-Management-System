Question:
In row-major order storage for a 2D array A[R][C] with base address B and element size S, what is the address of A[i][j] (0-indexed)?

Options:
A. B + (i * C + j) * S
B. B + (j * R + i) * S
C. B + (i + j) * S
D. B + (i * R + j * C) * S

Correct Answer: A

Explanation:
Row-major order lays out rows sequentially. There are C columns per row, so row i is preceded by i * C elements, plus j elements in the current row.
