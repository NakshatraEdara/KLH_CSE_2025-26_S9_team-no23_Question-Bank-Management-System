Question:
What is Donald Knuth's Algorithm X, and what data structure makes it exceptionally efficient for exact cover backtracking problems?

Options:
A. Dancing Links (DLX), which uses doubly linked circular lists to achieve O(1) node covering and uncovering
B. Suffix Tree with LCP array
C. Fibonacci Heap
D. Fenwick Tree with lazy propagation

Correct Answer: A

Explanation:
Dancing Links (DLX) represents a sparse matrix using circular 4-way linked nodes (left, right, up, down). Removing and restoring matrix columns and rows takes O(1) pointer operations without memory allocation.
