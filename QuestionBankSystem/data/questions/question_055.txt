Question:
What is the optimal algorithm to convert an arbitrary Binary Search Tree of n nodes into a balanced BST in O(n) time and O(1) auxiliary space?

Options:
A. Day-Stout-Warren (DSW) algorithm
B. Euler tour flattening
C. Tarjan's offline balancing
D. Floyd's cycle conversion

Correct Answer: A

Explanation:
The Day-Stout-Warren algorithm first flattens the BST into a vine (linked list) via right rotations, then performs precise sequences of left rotations to build a complete balanced tree in O(n) time and O(1) space.
