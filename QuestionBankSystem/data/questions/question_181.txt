Question:
What algorithm does A* degenerate into when the heuristic function h(n) is identically 0 for all nodes?

Options:
A. Dijkstra's algorithm
B. Depth-First Search
C. Kruskal's algorithm
D. Floyd-Warshall algorithm

Correct Answer: A

Explanation:
When h(n) = 0 for all n, f(n) = g(n) + 0 = g(n), which selects nodes strictly by lowest cost from source, identical to Dijkstra's algorithm.
