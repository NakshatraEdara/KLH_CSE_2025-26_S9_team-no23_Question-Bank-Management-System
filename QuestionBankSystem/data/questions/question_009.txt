Question:
How can a Min-Stack support push, pop, and getMin all in O(1) worst-case time?

Options:
A. By maintaining an auxiliary stack that tracks the current minimum at each state
B. By sorting the stack after every push operation
C. By using a self-balancing binary search tree inside the stack
D. By performing linear scan during getMin

Correct Answer: A

Explanation:
By maintaining a parallel auxiliary stack (or storing pairs of value and current min), each push and pop updates the minimum in O(1) time without scanning.
