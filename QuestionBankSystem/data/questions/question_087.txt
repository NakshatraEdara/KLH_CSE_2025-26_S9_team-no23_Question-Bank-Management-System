Question:
What is the standard array capacity allocated to safely represent a Segment Tree for an input array of size n?

Options:
A. 4 * n
B. 2 * n
C. n^2
D. n + 1

Correct Answer: A

Explanation:
The maximum number of nodes in a segment tree for an array of size n is 2 * 2^(ceil(log2 n)) - 1, which is strictly less than 4 * n.
