Question:
What is the Edit Distance between any string S of length n and the empty string ''?

Options:
A. n (requiring n deletions or n insertions)
B. 0
C. 1
D. infinity

Correct Answer: A

Explanation:
Converting an empty string to string S requires inserting all n characters; converting S to empty requires deleting all n characters. Hence, distance is n.
