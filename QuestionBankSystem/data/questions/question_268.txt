Question:
Which algorithm computes optimal Global Sequence Alignment between two biological sequences?

Options:
A. Needleman-Wunsch algorithm
B. Smith-Waterman algorithm
C. Kruskal's algorithm
D. Tarjan's algorithm

Correct Answer: A

Explanation:
The Needleman-Wunsch algorithm is a classic global sequence alignment algorithm that aligns every residue across both sequences from end to end using dynamic programming.
