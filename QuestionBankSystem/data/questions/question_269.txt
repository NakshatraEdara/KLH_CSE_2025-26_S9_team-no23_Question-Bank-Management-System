Question:
Which algorithm computes optimal Local Sequence Alignment to identify highly similar matching regions between two sequences?

Options:
A. Smith-Waterman algorithm
B. Needleman-Wunsch algorithm
C. Floyd-Warshall algorithm
D. Hopcroft-Karp algorithm

Correct Answer: A

Explanation:
The Smith-Waterman algorithm computes local alignments. It sets negative scores in the DP recurrence to 0, allowing alignments to start and end at arbitrary high-scoring internal positions.
