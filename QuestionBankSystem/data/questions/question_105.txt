Question:
What is the worst-case search time complexity in a B-Tree containing n keys with order m?

Options:
A. O(log_m n)
B. O(m * n)
C. O(n / m)
D. O(m^2)

Correct Answer: A

Explanation:
The maximum height of a B-tree of order m is bounded by O(log_(m/2) n) = O(log_m n). With binary search within each node taking O(log m), total time is O(log n), but disk page accesses are O(log_m n).
