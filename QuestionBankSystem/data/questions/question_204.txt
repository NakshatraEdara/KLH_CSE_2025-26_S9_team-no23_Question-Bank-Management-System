Question:
Under what condition is the standard greedy coin change algorithm guaranteed to produce the optimal (minimum) number of coins?

Options:
A. When the coin denomination system forms a Canonical Coin System (such as standard US currency)
B. For any arbitrary set of positive coin denominations
C. Only when all coin denominations are odd
D. Only if there are exactly 2 coin denominations

Correct Answer: A

Explanation:
For arbitrary coin denominations (e.g. {1, 3, 4} for total 6), greedy picks 4 + 1 + 1 (3 coins) while optimal is 3 + 3 (2 coins). Greedy works only on canonical coin systems.
