Question:
What is the time complexity of solving the 0/1 Knapsack problem with n items and maximum weight capacity W using Dynamic Programming?

Options:
A. O(n * W) pseudo-polynomial time
B. O(2^n) strictly
C. O(n log W)
D. O(W^2)

Correct Answer: A

Explanation:
The standard DP table has dimensions (n + 1) x (W + 1), with each cell computed in O(1) time. Since W depends on numeric magnitude rather than bit-length, the complexity is pseudo-polynomial O(n * W).
